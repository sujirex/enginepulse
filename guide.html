Overview

EnginePulse is a comprehensive ship engine and D.G. test management application designed for marine engineers, superintendents, and class surveyors. It covers the complete lifecycle of machinery commissioning from initial pre-start checks through long-endurance trials and predictive maintenance.

All data is stored locally in your browser (no internet connection required after loading). This makes it suitable for use at shipyards, anchorage, and sea trial operations where connectivity is limited.

💡 EnginePulse works fully offline once the page is loaded. Bookmark it for use without an internet connection.

Getting Started

Workflow

1
Open the Dashboard and fill in vessel details, main engine particulars, D.G. specs, and surveyor information.
2
Run tests module by module — each page auto-saves as you type. Module status (Pending / In Progress / Done / Signed) reflects on the dashboard.
3
Export data from each module as Excel sheets for your records.
4
On the Sign-off page, the surveyor selects completed tests, draws their signature, and generates a signed PDF certificate.

Dark / Light Mode

Click the ☀ / 🌙 toggle in the top-right of the navbar. Your preference is remembered across sessions.

Data Storage

All data is saved in your browser's localStorage. Data persists through page reloads and browser restarts. Clearing browser data will erase all entries — use the Excel export before clearing.

⚠️ Do not use Private / Incognito windows as localStorage is cleared when the window closes.

Module Status

Each module card shows its current status. Click the module name or use the navbar to navigate to it. The dashboard progress tiles show overall completion.

Commissioning Test

Covers all pre-start safety checks, device trip tests, alarm verification, cold/slow turning, and first fire. Complete this module before any load test.

Pre-Start Checklist

24 standard pre-start items covering lube oil, cooling water, fuel system, control air, starting air, and crankcase ventilation. For each item select Pass / Fail / N/A and add a remark if needed.

Safety Device Trips

10 critical safety systems (LO low pressure, overspeed, cooling water HH, crankcase pressure, etc.). Enter the set point and actual recorded trip value. The result is automatically assessed against class tolerances.

Alarm Checklist

15 alarm points. Verify each alarm operates at its set point. Select Pass / Fail / N/A per alarm.

Cold / Slow Turning

Record the number of turns on air alone before first fire, crankcase condition, and any abnormalities observed.

Excel Export

Exports 3 sheets: Pre-Start Checks, Safety Device Trips, and Alarm Tests. All pass/fail results and remarks are included.

D.G. Load Test

Step load test for diesel generators per class rules. Tests from 0% to 110% load with voltage and frequency regulation calculations.

Generator Nameplate

Enter rated kVA, kW, voltage, frequency, power factor, and RPM from the generator nameplate. These are used as reference values for regulation calculations.

Step Load Table

Six load steps: 0% / 25% / 50% / 75% / 100% / 110% of rated kW. For each step record:

kW Applied
Actual load applied (auto-calculates target kW from step %)
kVA
Auto-calculated: kW ÷ power factor
Voltage (V)
Terminal voltage measured under load
Frequency (Hz)
Frequency measured under load
Power Factor
Measured PF at this load step
RPM
Engine speed under load
Exhaust Temp (°C)
Average exhaust manifold temperature

Regulation Calculations

The app automatically calculates:

Voltage Regulation % = (V_no-load − V_full-load) / V_full-load × 100
Frequency Regulation % = (Hz_no-load − Hz_full-load) / Hz_full-load × 100
Class limit: both must be ≤ ±5%

A Pass/Fail badge is shown based on class rules. If VR or FR exceeds 5%, the badge turns red.

Parallel Operation

8-item checklist for generator paralleling tests: synchroniser operation, load sharing, bus bar protection, preferential trip sequence, etc.

Additional Tests

12-item checklist covering insulation resistance, earth fault detection, sequential starting, AVR performance, and governor response.

Load Chart

Dual-axis chart showing kW bars vs voltage line and frequency line across load steps. Useful for identifying voltage droop or frequency instability.

Sea Trial

Full performance sea trial covering speed runs, progressive speed table, crash stop, maneuvering, and fuel consumption measurement.

Speed Trial

Minimum 4 runs (2 in each direction) to cancel current effect. Enter direction, time (mm:ss), and distance (nautical miles). Speed is auto-calculated. Mean speed is compared against contract speed with a pass/fail result.

💡 The IMO standard requires runs in reciprocal directions. Class societies typically accept the mean of paired runs as the corrected speed.

Progressive Speed Table

9 RPM steps from ~50% to 100% MCR. For each step record power, speed, fuel rate, T/C inlet/outlet temps, exhaust cylinder average, charge air temp, LO pressure/temp, and cooling water temp. SFOC (g/kWh) is auto-calculated from fuel and power entries.

SFOC Calculation: fuel consumption (g/h) ÷ shaft power (kW)
Typical range: 165–195 g/kWh at NCR for modern two-stroke engines

Crash Stop

Record initial speed, RPM, time from astern order to stopped, stopping distance, maximum astern RPM achieved, and maximum cylinder / exhaust temperatures during the stop.

Maneuvering Checklist

10 items including bow thruster operation, stern thruster, stabilisers, anchor windlass, mooring winches, and tug connection points.

Fuel Consumption

Enter trial duration (hours), total fuel consumed (metric tonnes), and average power. SFOC is auto-calculated and compared to maker's guarantee.

Long Trial / Endurance Test

Continuous endurance run at specified load. Class societies require 4–24 hours at NCR. The app logs repeated readings at set intervals and flags alarms automatically.

Recording Readings

Fill in the Quick Entry panel and click Add Reading. The timestamp is auto-populated. Parameters logged per reading:

RPM · kW · Shaft RPM · Fuel rate (L/hr) · Exhaust avg (°C) · T/C in/out (°C) · Charge air temp (°C) · Scav air press (bar) · LO press (bar) · LO temp (°C) · FW temp (°C) · SW temp (°C) · Remarks

Alarm Highlighting

Any reading where LO temp exceeds the limit or exhaust temp exceeds the limit is highlighted in red in the table, and a toast alert is shown at the time of entry.

Trend Chart

Live multi-line chart updating as readings are added. Shows RPM, kW, exhaust temperature, and LO temperature on dual Y-axes. Useful for identifying gradual drift or sudden anomalies during the run.

Summary Statistics

Auto-calculated average, maximum, and minimum for RPM, kW, exhaust temp, and LO temp across all readings.

Predictive Analysis

Tracks running hours, maintenance schedules, performance trends, and estimates Remaining Useful Life (RUL) for the main engine.

Running Hours Log

Log each run period with start date/time and end date/time. Running hours are auto-calculated. Cumulative total is shown and used for all maintenance schedule calculations.

Enter your vessel's average daily running hours to get estimated calendar due dates for each interval.

Performance Trend Log

Log periodic performance checks (date, hours, RPM, power, SFOC, exhaust temp, LO consumption, vibration level). Four Chart.js trend charts display historical patterns for SFOC, exhaust temperature, LO consumption, and vibration.

RUL Estimator

Remaining Useful Life is estimated as:

Adjusted Life = Design Life × Condition Factor × Maintenance Factor
RUL = Adjusted Life − Hours Consumed
% Life Consumed = Hours Consumed / Adjusted Life × 100
Design Life (h)
Maker's rated design life — typically 100,000–150,000 h for a 2-stroke
Condition Factor
0.5–1.0 based on wear measurement results (1.0 = like new)
Maintenance Factor
0.5–1.0 based on maintenance history quality (1.0 = fully maintained)

Upcoming Events

Maintenance items where remaining hours are less than 15% of the interval are shown as forecast cards, making it easy to plan ahead for the next port call.

Surveyor Sign-off

The final step in the commissioning workflow. The class surveyor selects the tests they witnessed, enters their details, draws a digital signature, and generates a class-ready signed PDF certificate.

Selecting Tests

Check the box next to each test the surveyor witnessed and is certifying. Each module shows its current completion status. Only modules marked Done or In Progress can be signed off.

Digital Signature

Draw your signature directly on the signature pad using a mouse or stylus. On a tablet, use your finger or stylus. The signature is captured as an image and embedded in the PDF.

💡 Click Save Signature after drawing to ensure your signature is stored locally. It will be restored if you navigate away and return.

Witness Signature

The owner's representative or chief engineer may also sign in the witness panel. Enter their name and designation in the witness details section.

Generate Signed PDF

Click Generate Signed PDF to produce a class-ready certificate containing:

  • Vessel particulars from the Dashboard
  • List of all certified tests with check marks
  • Surveyor details, date, and location
  • Digital signature image
  • Witness details and signature
  • Overall remarks

Finalise & Lock

Click Finalise & Lock to set all signed modules to status "Signed" on the dashboard. This confirms the sign-off is complete. You can unlock using the Unlock button if corrections are needed before the PDF is submitted.

⚠️ Once you submit the PDF to the class society, keep a copy saved locally. Clearing browser data will remove all stored data.

Export Options

Excel Export (per module)

Each module has an Export Excel button that downloads an .xlsx file via SheetJS. Worksheets are structured with headers and formatted data ready for submission to class or owner.

Print

Every module has a print button. The print stylesheet hides the navbar, sidebar, and non-print elements, producing a clean hardcopy of the current module's data.

Signed PDF (Sign-off module)

Generated from the Sign-off page using jsPDF. Contains vessel particulars, certified test list, surveyor details, and embedded digital signature. Suitable for submission to class society as a supporting document.

💡 For official class records, the Excel export serves as the raw data attachment and the signed PDF serves as the cover certificate.

Tips & Offline Use

Using Offline

Open EnginePulse while connected to the internet. Once loaded, all functionality works without a connection — no API calls are made. You can close and reopen the tab and all your data remains intact.

Multiple Vessels

EnginePulse currently supports one active project per browser. To work on a second vessel, use a different browser profile or clear the data and start fresh after exporting.

Tablet / Stylus

The signature pad works with capacitive touchscreen styluses and S-Pen on Android tablets. For the best result, rest your palm on the screen only after beginning the stroke — the pad tracks the first contact point as the pen tip.

Keyboard Shortcuts

Tab
Move between form fields
Ctrl + P
Print current module
Ctrl + S

Backup Your Data

Export your Excel files regularly, especially before long trial and after sea trial. The Sign-off PDF should be downloaded immediately after generation. Browser updates and clearing site data will erase localStorage.

💡 Recommended workflow: Export Excel from each module after completion, then generate the signed PDF at the end. Keep both in the vessel's electronic record system.
